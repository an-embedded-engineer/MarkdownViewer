# Multi-tab Link Target

この文書は`multi_tab_links.md`から開くrelative Markdown linkのtargetである。

[Back to the navigation sample](multi_tab_links.md)

## Before the Anchor

このsectionは、anchor scrollの移動先が文書先頭と異なることを確認するためのspacerである。

### Spacer A

The link target tab may already be open or may need to be created.

### Spacer B

Following the same link must not create a duplicate tab.

### Spacer C

The active preview should move to the heading below.

### Spacer D

The source tab should remain open after navigation.

## Anchor Destination

relative Markdown linkの遷移後、このheadingが表示領域へscrollされれば確認成功である。
